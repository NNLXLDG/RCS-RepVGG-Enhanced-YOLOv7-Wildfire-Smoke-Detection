## 架构图与YAML配置对应的索引标注

图片中的架构:

YAML配置中主要层:
- backbone: [0] 到 [26] 层 (与图中蓝色虚线框内部分对应)
- head: [27] 到 [58] 层 (与图中黄色虚线框内部分对应)
- 检测头1: [54] -> [55] (从P4特征)
- 检测头2: [56] -> [57] (从P5特征)

每个RepVGG模块在图中标注了stride参数，对应YAML配置中的步长：
