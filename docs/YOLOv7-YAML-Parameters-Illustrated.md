# YOLOv7 YAML参数图解

本文档通过图形化方式解释YOLOv7配置文件中的参数含义，特别是`[-1, 1, RepVGG, [channels, kernel_size, stride]]`格式中各参数的作用。

## YAML基本参数结构

```
[from, number, module, args]
```

## 参数图解

```
            ┌─ from: 输入来源
            │  -1表示上一层
            │  正整数表示特定层索引
            │  [x,y]表示多层输入
            │
[-1, 1, RepVGG, [64, 3, 2]]
     │     │     │  │  │
     │     │     │  │  └─ stride: 步长
     │     │     │  │     1表示不改变特征图大小
     │     │     │  │     2表示将特征图尺寸减半
     │     │     │  │
     │     │     │  └─ kernel_size: 卷积核大小
     │     │     │      通常为3，表示3×3卷积
     │     │     │
     │     │     └─ channels: 输出通道数
     │     │         决定该层输出特征图的深度
     │     │
     │     └─ module: 模块类型
     │         如Conv, RepVGG, RCSOSA等
     │
     └─ number: 模块重复次数
         1表示单个模块
         >1表示堆叠多个相同模块
```

## YAML参数如何影响模型结构

### from参数的影响

```
       ┌───────┐
    ┌─▶│ 层A   │───┐
    │  └───────┘   │
    │              │
┌───┴───┐      ┌───▼───┐
│ 输入层 │      │ 层C   │
└───────┘      └───────┘
    │              ▲
    │  ┌───────┐   │
    └─▶│ 层B   │───┘
       └───────┘

# 对应YAML:
# 层A: [0, 1, Conv, [...]]
# 层B: [0, 1, Conv, [...]]
# 层C: [[1, 2], 1, Concat, [1]]
```


## 常见模块参数解析

### RepVGG模块

```yaml
[-1, 1, RepVGG, [64, 3, 2]]
```

参数含义:
- 输出通道数: 64
- 卷积核大小: 3×3
- 步长: 2 (特征图尺寸减半)

### RCSOSA模块

```yaml
[-1, 2, RCSOSA, [128]]
```

参数含义:
- 重复次数: 堆叠2个RCSOSA模块
- 输出通道数: 128

### SPPF模块

```yaml
[-1, 1, SPPF, [512, 5, 9, 13]]
```

参数含义:
- 输出通道数: 512
- 池化核大小: 5×5, 9×9, 13×13

## 实际应用示例

## 总结

YOLOv7 YAML配置中的参数`[-1, 1, RepVGG, [64, 3, 2]]`各部分含义:

1. **-1**: 输入来源为前一层
2. **1**: 只创建一个该类型模块
3. **RepVGG**: 模块类型为RepVGG
4. **[64, 3, 2]**: 参数列表
   - 64: 输出通道数
   - 3: 卷积核大小为3×3
   - 2: 步长为2

理解这些参数的含义对于修改和优化YOLOv7架构至关重要，它们直接决定了网络的连接方式、层数、特征维度和感受野大小。
