# 超参数优化详细说明

## 基于smokefire数据集的深度优化策略

### 数据集挑战分析
1. **严重类别不平衡**: smoke:fire = 2.17:1
2. **小目标较多**: 平均目标大小176.47像素
3. **目标密度适中**: 每图平均1.99个标注
4. **形状不规则**: fire通常较小且形状多变，smoke较大且不规则

### 优化核心策略

#### 1. 焦点损失 (Focal Loss) 强化
```yaml
# 原始配置 → 优化配置
fl_gamma: 0.0-0.5 → 0.6-0.9
```
- **基础模型**: 0.7 (中等强度)
- **RepVGG系列**: 0.6-0.7 (利用分类优势)
- **RCSOSA系列**: 0.7-0.75 (特征丰富补偿)
- **SimAM系列**: 0.6-0.75 (注意力增强)
- **终极组合**: 0.9 (最强配置)

#### 2. 分类损失权重显著降低
```yaml
# 原始配置 → 优化配置  
cls: 0.3-0.5 → 0.25-0.35
```
**理由**: 严重类别不平衡需要降低分类损失权重，避免模型过度关注多数类

#### 3. 目标检测损失权重提升
```yaml
# 原始配置 → 优化配置
obj: 1.0-1.2 → 1.15-1.35
```
**理由**: 小目标较多，需要增强目标检测能力

#### 4. 锚点阈值优化
```yaml
# 原始配置 → 优化配置
anchor_t: 4.0 → 3.2-3.8
```
**理由**: 降低锚点阈值更好地匹配小目标

#### 5. IoU阈值差异化设置
- **强分类模型** (RepVGG系列): 0.17-0.18 (更宽松，增加正样本)
- **精确定位模型** (RCSOSA系列): 0.24-0.27 (更严格，提高定位精度)
- **平衡模型**: 0.20 (标准配置)

## 各模型优化重点

### 1. 基础CSP-IDetect
**策略**: 稳定优化，重点解决类别不平衡
```yaml
cls: 0.3          # 降低分类权重
obj: 1.3          # 提高目标检测
anchor_t: 3.5     # 适配小目标
fl_gamma: 0.7     # 中等焦点损失
```

### 2. RepVGG系列
**策略**: 利用强分类能力，激进优化
```yaml
cls: 0.26-0.28    # 最低分类权重
iou_t: 0.17-0.18  # 最宽松IoU
fl_gamma: 0.6-0.7 # 适中焦点损失
```

### 3. RCSOSA系列  
**策略**: 发挥特征丰富优势，追求精确定位
```yaml
cls: 0.3-0.32     # 适度分类权重
iou_t: 0.24-0.25  # 高精度IoU要求
fl_gamma: 0.7-0.75 # 较强焦点损失
```

### 4. SimAM系列
**策略**: 平衡空间注意力，中庸优化
```yaml
cls: 0.3-0.35     # 平衡分类权重
iou_t: 0.18-0.20  # 适中IoU
fl_gamma: 0.6-0.75 # 弹性焦点损失
```

### 5. 终极组合 (RepVGG+RCSOSA+SimAM)
**策略**: 三重优势协同，极致优化
```yaml
cls: 0.25         # 最激进分类权重
obj: 1.35         # 最强目标检测
iou_t: 0.27       # 最高精度要求
anchor_t: 3.2     # 最适合小目标
fl_gamma: 0.9     # 最强焦点损失
```

## 训练建议

### 1. 收敛监控
- **早期阶段** (1-50 epochs): 关注分类损失下降
- **中期阶段** (50-150 epochs): 关注目标检测损失
- **后期阶段** (150+ epochs): 关注IoU提升

### 2. 学习率调度
- **RepVGG系列**: 更长预热 (5-5.5 epochs)
- **RCSOSA系列**: 适中预热 (4 epochs)  
- **SimAM系列**: 标准预热 (3.5 epochs)

### 3. 验证指标
- **主指标**: mAP@0.5 (类别不平衡场景更重要)
- **辅助指标**: mAP@0.5:0.95, Recall, F1-score
- **速度指标**: FPS, 推理时间

### 4. 超参数微调空间
如果某个模型表现不如预期，可以在以下范围内微调：
```yaml
cls: ±0.02         # 分类权重微调
obj: ±0.05         # 目标检测权重微调
fl_gamma: ±0.1     # 焦点损失微调
anchor_t: ±0.2     # 锚点阈值微调
iou_t: ±0.02       # IoU阈值微调
```

## 特殊场景优化

### 实时检测场景
- **推荐**: RepVGG或RepVGG+SimAM
- **优化**: 可适当降低数据增强强度，提高推理速度

### 高精度场景
- **推荐**: 终极组合或RCSOSA+SimAM
- **优化**: 可增加训练epoch数，使用更强数据增强

### 部署受限场景
- **推荐**: SimAM或基础CSP
- **优化**: 关注模型大小和计算复杂度
